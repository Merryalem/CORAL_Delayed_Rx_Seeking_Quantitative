# Analysis Repository

This repository contains the data, code, and findings for the project.

## Directory Structure

* **`dataset`**: The dataset and codebook containing the perspective data collected and stored from the weedcup database.
* **`coral results/`**: Directory storing the output results of the analysis.
* **`script/`**: Contains the R scripts used to process the data and generate the findings.
